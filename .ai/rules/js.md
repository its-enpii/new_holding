# Js

## Use the h-14 form control standard
AppInput, AppSelect, SmartSelect, AppDatePicker, AppSwitch field, and default AppButton use h-14/min-h-14. AppButton compact (min-h-10) is only for inline contexts, topbars, and table actions. Use AppDatePicker instead of raw date inputs and prefer existing App* components for all page-level form controls.
